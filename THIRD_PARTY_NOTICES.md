# Third-party sources

- Earth day/night and Moon: official [three.js examples](https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets), re-encoded to WebP with Sharp. Source files: `earth_atmos_2048.jpg`, `earth_lights_2048.png`, `moon_1024.jpg`. Repository license MIT (`licenses/three-MIT.txt`). Static imagery, not a live feed. No generated travel photography.
- Boundaries: documented Natural Earth/world-atlas snapshot, read without modifying the source. SHA-256: `2c2af8e35947debe14ab911bd350fc2ad51a506c2e3db0b1623e6e12f9f9397b`. Natural Earth data public domain, world-atlas processing ISC. Crimea assigned to Ukraine. Geographic data reuse, not WordPress code migration.
- Country catalog and six synthetic SVG cards: user-supplied TTJ test assets reused at the user's instruction. No real travel facts/dates. This permission does not cover future third-party photography.
- Three.js (MIT), three-conic-polygon-geometry (MIT), d3-geo (ISC), SunCalc (BSD): notices in `licenses/`, versions in lockfile.
- Cormorant Garamond and Manrope: SIL Open Font License, self-hosted Fontsource. Notices included; no external font service.
- Astro/Sharp build tooling retain upstream licenses in dependencies. Preserve notices when redistributing dependency source.
